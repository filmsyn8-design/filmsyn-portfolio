# FILMSYN Portfolio

A cinematic, dark portfolio website for audiovisual designers and directors.

## 🚀 Quick Deploy to Vercel

1. Go to your GitHub repo
2. Delete ALL files except `.git` folder
3. Upload these files in this exact structure:
   ```
   filmsyn-portfolio/
   ├── app/
   │   ├── layout.jsx
   │   ├── page.jsx
   │   └── globals.css
   ├── package.json
   ├── next.config.js
   ├── tailwind.config.js
   ├── postcss.config.js
   ├── .gitignore
   └── README.md
   ```

4. Commit and push to GitHub
5. Go to Vercel → Your Project → Click **Redeploy**
6. Wait 2-3 minutes
7. Your site is live! 🎉

## 📁 File Structure

- `app/layout.jsx` - Root layout (REQUIRED for Next.js 13+)
- `app/page.jsx` - Main portfolio page
- `app/globals.css` - Global styles + Tailwind
- `package.json` - Dependencies
- `next.config.js` - Next.js config
- `tailwind.config.js` - Tailwind CSS config
- `postcss.config.js` - PostCSS config
